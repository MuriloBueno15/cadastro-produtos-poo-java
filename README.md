# Cadastro de Produtos-POO Java

## Descrição

O projeto Cadastro de Produtos é
uma aplicação desenvolvida em Java
com o objetivo de cadastrar e consultar
informações de produtos, como nome, preço e quantidade
disponível em estoque.

O sistema também permite calcular o valor
individual e total dos produtos em estoque,
além de realizar validações para impedir o cadastro
de informações inválidas, utilizando estruturas
condicionais e tratamento de exceções.

## Funcionalidades

- Consulta de nome, preço e quantidade dos produtos.
- Cálculo do valor individual e total dos produtos em estoque.
- Atualização das informações dos produtos por meio de métodos
  setters, permitindo modificar atributos privados de forma controlada.
- Validação de nome, preço e quantidade dos produtos, utilizando
  estruturas condicionais (`if`) para identificar dados inválidos,
  `throw` para lançar exceções e `try/catch` para tratá-las, impedindo
  o cadastro de nomes vazios e valores negativos.
